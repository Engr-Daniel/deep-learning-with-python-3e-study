## Definition of done for a code example

A code example counts as done only when:

1. It has actually been run.
2. The main inputs and outputs are understood.
3. Key tensor/array shapes are understood where relevant.
4. Any error or version mismatch is documented.
5. The observed result is compared with the intended lesson.
